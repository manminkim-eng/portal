## 🆕 Ver 5.0 — 디자인 통일 + 출력물 정합

소방웹이 **MANMIN WAP 39종 디자인 통일의 마스터**로 확정되었고, 이 도구는 그 기준을 적용한 결과다.

> **계산 로직은 1바이트도 변경하지 않았다.** 수식·상수·검증식·법령 인용문 모두 이전 버전과 동일하다.
> 변경 범위는 `<style>` 블록 · 출력 래퍼 · 폰트 토큰 · 버전 문자열뿐이며,
> **수치 토큰 다중집합 대조로 무변경을 검증**했다.

### 조정 내역 — v5.0

| # | 항목 | 기존 | 변경 (v5.0) |
|---|------|------|------------|
| ① | **고정폭 폰트** | `Noto Sans Mono` | `JetBrains Mono` + `Noto Sans KR` 폴백 (39종 공통) |
| ② | **법규 표기** | 구버전 혼재 | 현행 기준으로 정정 (아래 참조) |
| ③ | **버전 체계** | Ver 3.1 | **Ver-5.0 / CACHE v5.0** (전 39종 5.0 재출발) |

### 인쇄·JPG 해당 없음

이 도구에는 계산서가 없다. A4 인쇄·JPG 저장 항목은 적용되지 않으며,
v5.0 변경은 **버전 체계 통일 · 법규 표기 정정 · 폰트 토큰** 세 가지다.

### 법령 표기 — 일괄 정정

포털은 각 도구의 근거 기준을 안내한다. v5.0에서 **표기를 현행으로 일괄 정정**했다.

| 기준 | 정정 후 표기 |
|---|---|
| NFPC / NFTC 102 · 103 · 103A | 제2025-25호 · **2026.3.1 시행** |
| NFPC / NFTC 109 | 2025.12.31 공포 · **2026.3.1 시행** |
| NFPC / NFTC 501 | 제2024-52호 · 2024.10.1 시행 |

> 정정 전에는 2022.12.1 ~ 2026.3.1 표기가 혼재했다. **계산 도구가 아니므로 로직 영향은 없다.**

## 📦 파일 구성

```
portal/
├── index.html          ← 메인 앱 (Ver 5.0)
├── manifest.json       ← PWA 매니페스트
├── sw.js               ← 서비스 워커 (CACHE_VER = 'v5.0')
├── README.md
└── icons/              ← 아이콘 세트
```

## 🚀 배포

1. 폴더 내용물을 GitHub 저장소 루트에 업로드
2. `Settings` → `Pages` → `Source: main branch / (root)`
3. 배포 후 **Ctrl+Shift+R** (강력 새로고침) — SW 캐시 갱신
4. 화면 하단 각인이 `Ver-5.0` 인지 확인

## 🛠️ 캐시 문제 시

브라우저 콘솔(`F12`):
```javascript
clearPwaCache()   // 전체 캐시 초기화 → 자동 새로고침
```

다음 배포 시에는 `sw.js` 의 `CACHE_VER` 한 줄만 올리면 된다.
