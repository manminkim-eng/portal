## 🚀 배포

1. 폴더 내용물을 GitHub 저장소 루트에 업로드 (**백업본 `*_백업_*.html/js/md` 는 업로드 제외**)
2. `Settings` → `Pages` → `Source: main branch / (root)`
3. 배포 후 **Ctrl+Shift+R** (강력 새로고침) — SW 캐시 갱신
4. 화면 하단 각인이 `Ver-5.1` 인지 확인
5. 헤더 배너가 `2026.7.1 시행` 인지 확인

## 🛠️ 캐시 문제 시

브라우저 콘솔(`F12`):
```javascript
clearPwaCache()   // 전체 캐시 초기화 → 자동 새로고침
```

다음 배포 시에는 `sw.js` 의 `CACHE_NAME` · `STATIC_CACHE` 두 줄만 올리면 된다.
